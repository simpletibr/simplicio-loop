usage: simplicio-py token [-h]
                          {log-summary,diff-review,postconditions,retry,model-routing,context-cache}
                          ...

positional arguments:
  {log-summary,diff-review,postconditions,retry,model-routing,context-cache}
    log-summary         summarize token usage and savings events from a log
    diff-review         review a diff for risk, scope and verification gaps
    postconditions      check postconditions recorded by a task run
    retry               classify a failure and produce a bounded retry
                        decision

                        executing them
    context-cache       read, write or invalidate the repository context cache

options:
