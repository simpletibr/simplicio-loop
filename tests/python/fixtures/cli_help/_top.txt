                    {index,task,run,bench,cache,smoke,init,detect,status,claims,inspect,intake,doctor,fast,versions,env-export,mechanical-edit,changeset,edit,file,test,token,score-skill,runtime,prototype,memory} ...

  {index,task,run,bench,cache,smoke,init,detect,status,claims,inspect,intake,doctor,fast,versions,env-export,mechanical-edit,changeset,edit,file,test,token,score-skill,runtime,prototype,memory}
    index               index/cache the repo (once, or after changes)
    task                run a task
    run                 run a task, feature, sprint, or scratch goal
    bench               compare with vs without (real numbers)
    cache               inspect or clear completion cache
    smoke               check the deterministic-only adapter; never contacts

    init                install skill + UserPromptSubmit hook into ~/.claude/
    detect              heuristic: is a prompt a code-edit task
    status              show current simplicio-py run state
    claims              claims-gate checks and report generation
    inspect             inspect a target with mapper-backed context
    intake              parse raw task cards into the provider-free TaskSpec
                        v2 contract
    doctor              check deterministic readiness and dependency freshness
    fast                negotiate optional Simplicio Fast capabilities
    versions            report simplicio-mapper installed/declared/tested
                        versions, drift, and this repo's own component-release
                        manifest (issue #232)
    env-export          print shell-safe exports from a dotenv file without
                        sourcing it
    mechanical-edit     execute simplicio.mechanical-edit/v1 dry-run or apply
    changeset           execute simplicio.fast.changeset/v2 through the
                        mechanical-edit boundary
    edit                apply a mechanical edit plan via simplicio-runtime
                        when available
    file                read raw file contents
    test                run a test command and report results
    token               token-efficient execution primitives
    score-skill         deterministic SkillOpt-style scorer for skill/law text
    runtime             runtime-facing dev-cli contracts
    prototype           Prototype-First plan, scaffold, validate and promotion
                        gate
    memory              cross-vendor memory handoff (markdown + git under
                        ~/.simplicio/memory)
