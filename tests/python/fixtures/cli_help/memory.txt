usage: simplicio-py memory [-h]
                           {init,store,recall,validate,handoff,backup,restore} ...

positional arguments:
  {init,store,recall,validate,handoff,backup,restore}
    init                create the memory store
    store               append a note
    recall              keyword search over stored notes
    validate            audit markdown memory store integrity
    handoff             build a deterministic cross-vendor handoff packet from
                        recall hits
    backup              create a hash-bound memory backup
    restore             preview or apply a hash-bound memory restore

options:
  -h, --help            show this help message and exit
