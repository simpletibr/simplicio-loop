# Issue #1346 — evidence

## Part 1 — failed verification is retryable

`simplicio-dev-cli edit --apply` exits 0 with `applied` even when its nested
`mutation_receipt.verification.status` is `failed`. `runner._execute_operator_unleased`
now reads that (`_devcli_verification_failed`) and treats the attempt as a
failure: the operator receipt records `reason_code: verification_failed` plus
the real `devcli_returncode`, the checkpoint rolls the edit back, the Mapper
operation completes as `failed`, and the next `tick` re-applies the current
`edit-plan-<N>.json`.

The rollback used to refuse with `changed_paths_outside_checkpoint_scope`
because verifier caches (`__pycache__`) and paths already dirty before the
attempt (e.g. `tasks.md`) counted as the attempt's own changes. The checkpoint
now records `dirty_before`, and `_restore_operator_checkpoint` ignores tool
caches and non-target paths that were dirty before.

Test (real installed Mapper + dev-cli, no mocks):
`tests/test_failed_verification_retry_1346_system.py` — wrong plan → `blocked`
+ `verification_failed` + rolled back + completion `failed`; corrected plan →
`tick` → `applied`, `mul(3, 4) == 12`. MEASURED: 1 passed (60 s).

## Part 2 — one deadline for the whole orient call

`_orient_core` takes one monotonic deadline (`SIMPLICIO_LOOP_ORIENT_BUDGET_S`,
default 120 s), shared by every task of `orient --brief`. The Mapper index gets
the remaining budget, and so does the `simplicio-mapper orient` survey
subprocess (before: a fixed 180 s timeout outside the budget). A timeout raises
`OrientBudgetExceeded` (reason_code `orient_budget_exceeded`), which both
`orient` forms already render as typed BLOCKED JSON.

Test: `tests/test_orient_total_deadline_1346_unit.py` — fake Mapper whose
`orient` sleeps 30 s, budget 2 s → both forms return BLOCKED JSON in < 10 s.
MEASURED: 7 passed (11 s) with `tests/test_orient_mapper_index_budget_unit.py`.

Environment: tests run with `/opt/simplicio-loop/bin/python`, where the
monorepo's `packages/mapper` (0.26.34) and `packages/dev-cli` (0.18.16) are
installed editable.
