# Issue #1342 — evidence

Delivered with direct edits (TDD + git), not the loop's wave (maintainer
decision, 2026-09-26).

## What changed

1. **Immutable contract header.** Every contract document (the 10
   `.claude/skills/*/SKILL.md`, their `references/*.md`, `AGENTS.md`,
   `bench/llm_ab/STANDARD.md`, `contracts/**/*.md`) starts, right after the
   YAML frontmatter, with a `simplicio-contract` block: `contract`, `schema`,
   `purpose`, `rules`. It has no versions, dates, counts or run ids.
   `scripts/contract_headers.py` checks it (it also runs from
   `scripts/check.py` next to the claims audit) and pins each header's bytes in
   `contracts/headers.lock.json`. A header change needs a
   `header-change: <path>` line in CHANGELOG.md. No contract had volatile data
   in its first lines, so none had to move to a footer.
2. **Loop JSON order.** `simplicio_loop/json_order.py::stable_first` puts
   `schema` and stable fields first and volatile ones (`run_id`, `*_at`,
   durations, receipt/state-dir paths) last, recursively. Applied to what
   `orient`, `orient --brief` (keeps `route` first), `prepare`, `verify`,
   `tick` and `batch`/`wave` print, in compact and pretty forms.
3. **Per-call cache gate.** `bench/llm_ab/report.py::first_cold_call` finds
   the first simplicio call after a task's first one with
   `cached_tokens == 0`. The report names it with a probable cause, and
   `standard.py` exits 3 for the standard matrix and for `--ablation`.
4. **"What the model sees / Token effect / KV cache effect"** section in every
   SKILL.md, the root README, `packages/mapper/README.md`, and a new
   `packages/dev-cli/README.md` (its `pyproject.toml` already declared
   `readme = "README.md"`, but the file was missing). `contract_headers.py`
   fails when a section is missing.
5. Mirrors re-synced and `docs/LLM_ORIENTATION.toon` re-pinned
   (`scripts/refresh_orientation_pins.py`).
