# simplicio-loop 3.51.0

This release runs setup during install and requires an owner list for the 24/7 watcher.

**Upgrade notes**

- **24/7 watcher:**
  - Set `SIMPLICIO_247_OWNERS` to the GitHub owners to watch. An owner is an organization or a user. Separate the owners with commas.
  - The service refuses to start without this variable.
  - The claim, lease and status keys change from `repo#N` to `owner/repo#N`.
  - Before you upgrade a running service:
    1. Stop the service.
    2. Remove `baseline.json`, `claims.json` and `fixes.json` from the service state directory. See `docs/WATCHER_247.md`.
  - The service no longer uses old work folders named `<repo>` without an owner. You can remove them.
- **Standalone binary:**
  - This release removes the standalone binary. The binary was never published.
  - Install with `pip install simplicio-loop`. Update with `simplicio-loop update`.
  - For a git checkout, use `git pull` and `bash scripts/dev_install.sh`.

**Highlights**

- Install: `simplicio-loop install` runs `setup` at the end, also without a terminal (#1841).
- Python: `setup` detects a usable Python. A Microsoft Store alias does not count. If `setup` finds no usable Python, it installs Python 3.11 (#1842).
- Evidence tools: `setup` checks and installs `@playwright/test` 1.64.1 with its Chromium (#1843). `setup` only checks Node.js 22 or later. `doctor` lists one row per tool.
- Explainer: `setup --with-hyperframes` installs the optional hyperframes explainer. Without the flag, `doctor` shows it as optional, not as a warning.
- Hooks: `pip install simplicio-loop` and `simplicio-loop install` register the Stop and PreToolUse hooks in `.claude/settings.json`. The merge keeps every existing key and hook.
- 24/7 watcher: `SIMPLICIO_247_OWNERS` replaces the hardcoded `simpletibr` org and the `simplicio*` repo-name prefix filter.
- Hosts: The release wires eight more hosts: GitHub Copilot, OpenCode, Simplicio Agent (Hermes), Continue, Qwen Code, Gemini, Aider and OpenClaw. The catalog has 34 wired adapters and 0 listed hosts.
- Doctor: `doctor` checks Python against `requires-python` (3.11) and prints the interpreter path.
